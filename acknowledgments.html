Server Components

NuviPal's analysis gateway runs on Firebase Cloud Functions and uses the App Store Server Library for Node.js (Apache License 2.0, Copyright Apple Inc.) to verify subscription receipts. These components run on the server and are not part of the app you install.

AI Models

Meal analysis is performed by third-party AI models accessed through OpenRouter. The models are operated by their respective providers under their own terms and licenses, and are not distributed with NuviPal.

Nutrition Scoring

NuviPal's meal grading is derived from publicly documented nutrition scoring approaches. NuviPal is not affiliated with, endorsed by, or certified by any health authority or standards body.

Privacy Manifests

NuviPal includes a privacy manifest for app-level API use. Some open-source packages may also include their own privacy manifests when required by Apple platform rules.
